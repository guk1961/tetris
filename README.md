# Тетрис

Браузерная игра для компьютера и телефона: семь классических фигур, следующая фигура, подсказка места падения, счёт и ускорение после каждых десяти линий.

Размер стакана автоматически подстраивается под высоту и ширину окна. На большом экране кнопки находятся справа, на телефоне — под игровым полем. При изменении размера окна текущая партия продолжается.

## Запуск

Откройте `index.html` в браузере и нажмите «Начать игру». Установка и сервер не требуются. На телефоне используйте кнопки под игровым полем.

| Клавиша | Действие |
| --- | --- |
| ← / → | Движение |
| ↑ | Поворот |
| ↓ | Ускоренное падение |
| Пробел | Мгновенный сброс |
| P | Пауза / продолжение |

## Файлы

- `index.html` — автономная версия для браузера и GitHub Pages.
- `tetris.html` — исходный интерактивный фрагмент.
- `verify.cjs` — проверки правил игры и управления. Запуск: `node verify.cjs`.

## Публикация

В настройках GitHub Pages выберите публикацию из ветки `main`, папка `/ (root)`. Собственный домен не требуется.
